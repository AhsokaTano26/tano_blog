# Article signature font

`caveat-latin-400.woff2` is the unmodified Latin subset of Caveat Regular,
served locally for article author signatures.

- Typeface: Caveat, by Pablo Impallari / The Caveat Project Authors
- Project: https://github.com/googlefonts/caveat
- Source: https://fonts.googleapis.com/css2?family=Caveat:wght@400&display=swap
- License: SIL Open Font License 1.1, included in `Caveat-OFL.txt`

Characters outside this subset use the reader's installed handwriting fonts.
