# Twemoji artwork

These unmodified SVG icons come from [Twemoji v17.0.3](https://github.com/jdecked/twemoji/tree/v17.0.3/assets/svg), created by Twitter, Inc. and other contributors and maintained by the Twemoji community.

Graphics are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). See `LICENSE-GRAPHICS` in this directory for the full license.

Only icons used by the reaction picker are included. They are served locally; the application does not contact an emoji CDN. The original Unicode values remain the identifiers stored by the API.
