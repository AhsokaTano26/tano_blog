# BanG Dream! 图片表情

本目录收录 B 站 2024 年《BanG Dream! 少女乐团派对!》个性装扮中的 40 个角色表情，使用公开展示图片对应的 128px WebP 缩略图。文件保持 CDN 返回的内容，原图和缩略图地址见 `sources.json`。

来源：[B 站表情展示页](https://www.bilibili.com/opus/918031856354459666)；[B 站上架介绍](https://www.bilibili.com/opus/918346028898320386)。
