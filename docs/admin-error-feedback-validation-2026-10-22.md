# 后台错误提示核查记录

日期：2026-10-22。针对备机保存页脚返回 503、页面没有显示具体原因的问题，核查并补齐现有后台请求的反馈。服务器的主备写入限制保持不变。

## 提示规则

- 接口返回 JSON 原因时保留原文，并附上 HTTP 状态码。例如：`保存失败：备服务器只允许修改同步配置（HTTP 503）`。
- 代理返回 HTML 或空响应时，按状态显示可操作的中文说明，不把代理 HTML 放进页面。覆盖权限、冲突、限流、文件过大、服务不可用和超时等情况。
- 读取失败显示错误和重试，不显示成空列表、零计数或可直接覆盖的默认配置。
- 写入失败保留输入。写入已确认、后续读取失败时明确说明“已保存，但重新读取失败”，不自动重发写入。
- 设置与音乐馆保存期间继续输入的内容，不被随后返回的配置覆盖。旧的成功提示计时器不会清除后来的错误。
