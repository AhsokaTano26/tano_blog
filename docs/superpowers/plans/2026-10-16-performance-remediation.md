# 全站性能修复计划与执行记录

## 目标与依据

修复前台、管理后台及 Go/PostgreSQL 链路的已核实性能问题。依据本地隔离审计：3,000 篇约 32 KB 文章、30,000 媒体、10,000 图库条目、1,000,000 访问日志，以及生产构建浏览器验证。原始测量保存在 `/tmp/tano-blog-performance-audit/`，不是生产监控数据。

## 架构与约束

保留 Next.js App Router、React、Gin/GORM/PostgreSQL 和现有权限、资源密码、备份格式。原图与已发布文章内容不改变。不连接生产数据库，不覆盖 AGENTS.md，不推送或部署。对可独立修改的模块使用并行代理，交叉接口由主代理统一集成。关键回归先写测试；性能变化用同一隔离数据集复测。默认不自动删除已有历史日志；保留策略显式配置。

## 执行任务

- [x] **A — 文章渲染与编辑器**：Markdown 独立懒加载和记忆化；编辑模式不解析隐藏预览；延迟预览更新；修复上传占位符删除后的光标问题；保留粘贴/拖放上传、数学公式、Mermaid、图片尺寸、目录与滚动同步。验证交互和渲染回归。
- [x] **B — 播放器与动画**：关闭的播放列表不挂载全部封面；懒加载播放器；音乐可视化使用可复用缓冲区和局部 DOM/Canvas 更新，暂停/隐藏/减少动态效果时停止无用帧；滚动进度合帧。验证播放与切页连续性。
- [x] **C — 备份与同步**：流式导出/恢复 JSON，分批数据库写入，保留旧格式兼容与安全验证；消除全库内存复制及导出后无法恢复的问题；缩短同步写锁范围；长任务可观察且不会受普通请求 30 秒超时误伤。验证备份往返、失败回滚、同步一致性。
- [x] **D — API、权限与公共首屏**：401 只在管理页面触发登录跳转；所有请求可终止且不返回永不结束的 Promise；公共配置并发去重，音乐配置单独按权限获取；首页/文章服务端首屏数据；独立基础数据只加载一次。验证匿名阅读、密码资源、管理登录过期和首屏 HTML。
- [x] **E — 数据查询与分页**：列表投影不读取正文，全文搜索一次计算匹配集合；稳定排序与索引；系列进度轻量接口；图库/评论/归档分页及对应加载更多交互；媒体图库成员标记避免全量列表；修订列表只含元数据。验证分页完整性、排序、保密字段与 SQL 计划。
- [x] **F — 资源预算与上传**：请求上下文贯穿数据库，连接池/查询超时有界；上传提前类型检查、流式限额写盘、取消清理；Next 上传流式代理、合理请求体预算；上传进度/取消；HTTP 与邮件外部请求超时；不可变上传缓存与轻量封面。验证超限/取消请求、内存峰值和缓存头。
- [x] **G — 日志与统计**：有界异步批量访问日志、关闭时排空、队列丢弃可观测；统计限定时间范围并复用结果；可配置分批清理日志；查询索引和管理概览轻量计数。验证统计一致性、日志过滤/脱敏及百万日志基准。
- [x] **H — 集成验证**：前端测试、类型检查、lint、生产构建；Go 测试（含隔离 PostgreSQL）、vet；浏览器匿名文章/媒体/编辑器/音乐/管理流；复测慢查询、请求数、传输大小、取消、上传资源；独立代码复核。

## 执行记录

- 2026-10-16：用户授权全部修复、自动推进。初始工作区干净，基线提交 `58ed1bb`。本计划的任务状态与验证结果持续更新，尚未完成的项不得描述为已修复。
- A/B/D/E/F/G 的主要实现已经落盘；最终前端 81 项行为测试、类型检查与生产构建通过，lint 为 0 errors / 463 warnings（原基线 476 warnings）。包含隔离 PostgreSQL 的 Go 全套测试、vet 和构建通过。
- 备份流式测试：269.1 MiB JSON、28,000 条记录完整往返约 8.56 秒，采样峰值 HeapAlloc 35.2 MiB。同步快照固定数据库视图与硬链接后释放锁；取消、回滚和清理已有测试。
- 上传实测：专用 Next 流式路由完整转发 100 MiB 媒体与恢复请求；无效类型上游仅读取约 65 KB；取消传播到上游。Go 有效 100 MiB MP4 落盘、标签前后顺序与失败缩略图清理测试通过。
- Ruling：服务端渲染不信任用户自报 XFF。Go 看到 SSR 标记且存在有效 IP 封禁时返回 409，由浏览器执行一次真实权限检查；SSR 不计浏览量，hydration 单独记录。这保留封禁行为，代价是有活动封禁时匿名首屏内容退回客户端加载。
- Ruling：统计与日志默认近 30 天，指定历史范围最多 366 天；不静默清理已有日志。`ACCESS_LOG_RETENTION_DAYS` 为显式启用的分批保留策略。统计结果短缓存 15 秒；日期统一 UTC+8。
- 独立复核问题均已修复并回归：管理详情补标签/系列；站内通知在请求返回前落库；日志字段字节限额防整批失败；普通备份固定文件集；评论自引用外键跨批次恢复。详情系列测试原 fixture 缺少表，已检查所有准备数据错误并补齐迁移。
- 生产报错补修：文章创建自动生成 UUID 预览令牌；部分唯一索引只约束非空令牌，迁移先建立新索引再删除旧索引。新库、旧库、迁移幂等、历史链接保留、重复非空令牌拒绝均通过。真实 Next → Go → PostgreSQL 连续创建草稿与发布文章均返回 201，预览均返回正确文章。
- 浏览器回归发现并修复编辑器代码块崩溃：`editorComponents.pre` 从 `undefined` 改为原生 `pre`，真实 Markdown 与完整编辑器测试均先红后绿；生产浏览器公式、代码、粘贴图片、图片 50% 宽度、保存、媒体缩略图均通过。
- 最终日志收尾：普通列表先计数，空结果与越界分页避免窗口排序和重复扫描；游标分页不重复计数；等待统计缓存锁可取消。行为测试与执行计划已核对。
- 浏览器匿名正文、评论继续加载、登录、播放器跨公共页面保持音频节点与播放、日志游标分页均已验证。复测数据与限制见 [性能验证记录](../../performance-validation-2026-10-16.md)，运维参数见 [性能与容量指南](../../performance-operations.md)。
