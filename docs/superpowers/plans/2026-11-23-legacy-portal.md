# 旧版门户实施计划

目标是实现确认的旧版门户设计，并由后台控制开放。沿用 Next.js、Go、CSS Modules 和现有数据接口。设计见 "../specs/2026-11-23-legacy-portal-design.md"。

- [x] 通过 Go 路由测试验证默认关闭、配置写入与撤回、无缓存和非法值。新增公开状态接口，后台外观设置复用现有保存流程。
- [x] 为新版页脚接入状态，为 "/legacy" 整组路由提供动态服务端校验。覆盖直接访问、浏览器返回和已打开页面重新获焦。
- [x] 用独立旧版组件实现站首、导航、搜索、三列首页、分类文章列表、归档、详情、图库、友链和关于。详情复用受保护文章接口和 Markdown。小屏改为单列。
- [x] 用测试库验证设置保存、关闭后入口消失及所有旧版路由返回 404。浏览器检查检索、分页、图片、密码文章和移动布局，执行单测、lint、生产构建和 Go 检查。
