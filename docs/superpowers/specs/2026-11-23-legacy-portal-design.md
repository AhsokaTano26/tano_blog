# 旧版门户 UI

在现有博客旁新增一套早期中文政府门户风格的浏览界面，保留当前新版。用户已选择“保留新版，增加旧版入口”。

## 方案

- 独立 `/legacy` 路径：共用现有数据，页面外观与新版隔离，关闭时可直接阻断整组路由。采用此方案。
- 全站主题切换：会改变当前默认前台，和用户选择的并行入口不符。

## 页面和交互

旧版包括首页、文章列表及检索、文章详情、时光归档、图片馆、友情链接和关于。栏目导航、分页、搜索、正文图片和返回新版均可操作；文章密码访问沿用原有权限。首页取现有文章、热门文章、分类、友链和图库，显示真实标题、日期和计数。数据为空时显示简短空状态。

## 视觉

桌面中央为 1140px 宽的门户主体，使用宋体、深红站名、灰白背景、方角细框和浅蓝栏目标题条，正文按三列新闻式排版。后续参考早期门户组件示例，加入绿蓝双色双层导航、金色分类菜单、缩略图文章列表和数字分页。

首页发布牌放在日期和搜索工具栏中，滚动往返一趟。悬停或聚焦时暂停，开启减少动态效果时静止。右栏电子日历支持切换月份，显示北京时间、农历和年内天数。站点小统计读取已有文章、分类、图库和友链数据。小屏正文收成单列。

横幅使用 Mx. Granger 的金山岭长城实拍，经 WebP 压缩，并在页面上做淡蓝调色和裁切。[原图与 CC0 许可](https://commons.wikimedia.org/wiki/File:Great_Wall_at_Jinshanling.JPG)

旧版页头提供「登录」。登录页使用蓝色背景、银灰表单和钥匙图案，并调用现有密码及两步验证接口。忘记密码和通行密钥指向现有流程。旧版开关关闭时，登录页也返回 404。

## 开放控制

后台“设置 → 外观设置”新增“开放旧版界面”，默认关闭。保存后控制新版页脚的旧版入口；旧版页首和页脚提供“返回新版”。

关闭、未配置、非法配置或无法确认配置时，服务端不输出旧版内容，旧版 URL 返回 HTTP 404；这项校验覆盖直接请求和客户端导航。独立无缓存配置读取防止沿用一分钟的公共配置缓存。已打开页面在重新聚焦和定期校验时同步开放状态。仅管理员可修改设置。

## 实现与验证

沿用 Next.js、React、CSS Modules、Go 配置存储和现有公开 API；不复制数据库，不增加第三方运行依赖。旧版组件独立，主布局识别 `/legacy` 后不重复输出新版页头、横幅、浮动播放器和页脚。

回归覆盖默认关闭、开启、关闭后直接访问及导航、配置失败、设置保存、入口显隐、文章密码、搜索分页、图片和移动布局，并运行项目现有单测、lint、构建、Go 测试和 Chromium/WebKit 浏览器回归。
