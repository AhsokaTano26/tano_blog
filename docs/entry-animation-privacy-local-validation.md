# 后台进入动画：本地隐私验收

验收日期：2026-10-20。对象是当前本地代码及 Demo，尚未上线；不包含线上域名、CDN 或部署环境验收。

## 验收要求

没有有效管理员会话的新请求，不得通过应用的 HTTP 接口或公开静态资源取得已保存的动画自定义文字和图标。成功退出登录后，复制的旧 Cookie 和 Bearer 凭证必须失效。鉴权查询失败时必须拒绝访问。

以下四个操作均受服务端鉴权、管理员权限及相关会话状态校验保护；成功和拒绝响应均携带 `Cache-Control: private, no-store`，并按 Cookie、Authorization 区分响应：

- `GET /api/v1/admin/entry-animation`
- `PUT /api/v1/admin/entry-animation`
- `GET /api/v1/admin/entry-animation/player`
- `POST /api/v1/admin/entry-animation/preview`

图标以内联数据保存在私有配置中，不生成公开 uploads 文件。公开配置与通用后台配置不返回动画配置记录；预览不修改已保存配置。

## 本次发现与修复

退出接口原先忽略数据库撤销会话的写入错误，仍清除浏览器 Cookie 并返回成功。在该失败分支中，复制的旧凭证可能继续有效。

现在只有撤销成功才清除 Cookie 并返回成功；撤销失败返回 503，保留 Cookie 供重试，不再声称退出成功。先通过故障注入复现失败，再修复并验证成功退出后的旧凭证被拒绝。

实现：[auth.go](../backend/internal/handler/auth.go)。

## 自动化回归

新增 [TestEntryAnimationSavedContentBoundary](../backend/internal/handler/entry_animation_boundary_test.go)，使用隔离 PostgreSQL 数据及真实鉴权中间件。先保存有明确标记的自定义文字和 PNG 图标，再验证：

- 已授权访问成功后，匿名及无效凭证不能复用私有响应。
- 过期、签名错误、待二次验证、密码重置、已撤销版本及旧恢复代次凭证全部拒绝。
- 当前数据库中的非管理员角色、强制改密状态会覆盖旧令牌的权限。
- 数据库会话查询异常拒绝读取。
- 撤销会话失败不能返回退出成功或清除 JWT Cookie。
- 成功退出后，复制的 Cookie 和 Bearer 凭证均不能访问四个私有操作。
- 公开配置及通用后台配置不包含私有记录；拒绝响应不包含测试文字、图标或默认动画内容。

该测试包含 13 个子测试、96 次私有操作拒绝校验，已纳入常规 `go test ./...`，无需额外 CI 工作流。复跑时为测试提供 PostgreSQL：

```sh
cd backend
REQUIRE_TEST_DATABASE=1 go test ./internal/handler \
  -run 'TestEntryAnimation(SavedContentBoundary|PrivacyAndPersistence)$' -count=1
```

使用 `TEST_DATABASE_DSN` 指定测试数据库，勿将连接凭证写入仓库。

## 保证范围

上述结果证明的是当前版本在已覆盖访问路径和异常场景下满足验收要求，并通过回归测试持续检查。它不构成“任何环境、任何漏洞下绝不可能泄露”的绝对保证。

已经通过合法会话下载到客户端的内容不能被远程收回；持有仍有效的管理员凭证会被服务端视为已登录。服务器或数据库访问权限也不属于匿名 HTTP 访问。默认文案和动画实现存在于项目源码，公开站点标题本身仍是公开信息；本要求保护的是保存的自定义配置和私有图标。

本次未执行上线、提交或推送，也未进行浏览器视觉验收。上线后仍需针对实际反向代理和缓存配置复核同一组访问边界。
