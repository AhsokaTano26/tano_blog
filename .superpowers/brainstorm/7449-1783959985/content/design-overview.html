完整设计方案

瀑布流图片馆 — 后端独立表 + 前端 masonry 布局

1. 数据库模型

新建 GalleryImage 表：

id UUID PRIMARY KEY
url TEXT NOT NULL   // 图片地址
title VARCHAR(255)    // 标题（鼠标悬停显示）
description TEXT           // 描述（灯箱内显示）
width INT               // 原始宽度（用于计算 masonry 比例）
height INT               // 原始高度
sort_order INT            // 排序序号
created_at TIMESTAMP
updated_at TIMESTAMP

width/height 在上传时自动读取，masonry 布局用宽高比决定每列高度。

2. 后端 API

公开 GET /api/v1/gallery   // 返回所有图片（按 sort_order 排序） 管理员（需要 auth+csrf+admin） GET /api/v1/admin/gallery       // 列表 POST /api/v1/admin/gallery      // 新增 PUT /api/v1/admin/gallery/:id  // 更新 DELETE /api/v1/admin/gallery/:id  // 删除 PUT /api/v1/admin/gallery/reorder // 批量排序

3. 前端页面

📱 公开页 /gallery

  • CSS column 瀑布流布局
  • 页面加载时取图片宽高比
  • 点击图片 → 全屏灯箱（左右切换）
  • 灯箱显示标题 + 描述
  • 响应式：PC 3-4 列 → 平板 2 列 → 手机 1-2 列
  • 复用现有 ImageLightbox 组件
  • 页面风格和音乐馆统一

⚙️ 后台管理 /admin/gallery

  • 图片网格预览（缩略图）
  • 添加图片弹窗：媒体库选择 + URL 输入 + 标题+描述
  • 编辑 / 删除按钮
  • 拖拽或上下按钮调整排序
  • 侧边栏加「图片馆」入口
