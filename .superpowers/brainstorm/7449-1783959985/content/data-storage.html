数据存储方式

选了瀑布流，接下来决定后台数据怎么管理

A. SiteConfig JSON（推荐）

和音乐馆完全一样：

site_configs 表
key: "gallery_page_config"
value: JSON 数组 → 图片列表

后台: PUT /api/v1/admin/config
前端: GET /api/v1/config/gallery_page_config

优点

  • 无需新建接口/路由
  • 和音乐馆统一模式
  • 实现最快

缺点

  • 不支持分页
  • 图片量大时 JSON 臃肿

B. 独立数据库表

新建 gallery_images 表：

gallery_images {
  id, url, title,
  description, width,
  height, sort_order,
  created_at
}

优点

  • 支持分页、排序
  • 适合大量图片
  • 每张图可独立编辑

缺点

  • 需要新表+新接口
  • 实现复杂度高
